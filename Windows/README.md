# Packpier 0.1.30 for Windows x64 (preview)

Extract the entire ZIP on Windows 11 x64, then run `Packpier.Windows.exe` from the extracted folder. Keep the files together. This self-contained preview includes the .NET 10 Desktop Runtime, so no separate installation is needed.

The window lists P-Sign, Prism and Custom Background in a read-only marketplace. Select a plugin to see its version and description. The preview cannot connect to Codex, render effects, install plugins or enable them. Those features are available in the macOS edition.

## 简体中文

在 Windows 11 x64 上完整解压 ZIP，然后运行解压目录中的 `Packpier.Windows.exe`。请保留同目录的其他文件。预览包已内置 .NET 10 Desktop Runtime。

本预览仅提供只读插件市场，可查看 P-Sign、Prism 和自定义背景的版本与说明。连接 Codex、渲染效果、安装及启用插件属于 macOS 版功能。
