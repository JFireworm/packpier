# 会话列表主题 · 青瓷

针对 Mac 个人微信 3.8.7（28249）的原生主题组件。提供 AppKit 主题选择组件，并在 Packpier 中内置绑定到指定微信应用的贴窗适配器。

首次使用沿用宿主配色。选择青瓷后，普通行使用 `#F2F7F4`，置顶行使用 `#E2EEE8`，选中行使用 `#C4DDD1`。选中置顶会话时选中态优先。恢复默认或停用时，回调传入 nil，由宿主恢复原有绘制。

组件使用 AppKit。调用方持有 ConversationThemePicker，提供偏好存储、相邻的搜索框与加号视图，以及重绘列表的回调。停用时调用 detach()。这组接口供自有工具栏使用。微信测试副本走下述贴窗模式。

运行 `swift test` 可验证 AppKit 控件的插入、主题菜单动作、停用和恢复。测试使用独立的偏好存储。

## Packpier 贴窗模式

正式 Packpier 在「插件市场 → 目标应用 → 微信」中启用青瓷。允许 Packpier 使用辅助功能后，将已打开的微信切到前台。正式版匹配 /Applications/WeChat.app 的 3.8.7（28249）。

单独测试副本时，在独立标准账户登录后，打开共享目录内专用的 Packpier WeChat Test，在微信插件页开启「青瓷 · 会话列表贴窗」，为这个测试构建授权辅助功能，再从同页打开测试副本。测试构建默认进入微信页。进入微信消息首页后，在搜索框右端点击双色圆。

Packpier 仅在所匹配的微信位于前台时，通过辅助功能定位搜索框、列表和窗口边界，不读取搜索词或会话内容。色层位于列表上方并允许鼠标事件穿透。切回「微信默认」会移除色层，停用会同时移除按钮。未识别到控件时暂不显示，Packpier 显示识别状态。实际微信 28249 的控件可见性与真实交互需以微信实际窗口验收。

使用 `Scripts/build.sh --wechat-test` 构建独立应用。各测试用户分别保存开关与主题偏好。组件测试与 Packpier 的原生窗口回归分别用 `swift test` 和项目的 `Scripts/test.sh` 运行。
